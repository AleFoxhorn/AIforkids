# WonderPatch V1

画廊入口位于画板按钮左侧：在平板内以陈列架展示非空画板和已装裱作品，沿用各自保存的画框；点击画板作品可回到对象级编辑，导入整图只能重新装裱。名称旁已去掉圆点，双击名称打开编辑弹窗（键盘 Enter 也可）。长按拿起素材时，展开库自动缩回单行，单行库保持原处且不透明，放入画板后也不自动关闭。

素材库当前统一采用长按拖动：约 420ms 拿起后，拖到画布添加，拖到素材库顶部垃圾桶移出。短按素材不添加、不删除；直接滑动仍用于浏览。已取消点击删除模式，恢复入口仍可找回移出的素材，已有作品和原图不受影响。

最新反馈迭代：上传入口改为加号；修正入口用麦克风图标但仍是文字输入；短暂状态反馈由小恐龙气泡呈现。素材库管理模式可逐项移出素材并恢复，源图不删除、已有作品不受影响。拖动素材使用顶层临时图像，位于垃圾桶和工具栏之上，结束即回到画布渲染。

场景记忆现在是结构化事实而非用户原话，旧文本会尝试迁移。当前仅有离线保守规则，支持明确场景及鸟/鱼等排除条件；不确定或未识别表达不会记录成事实。建议具体为小鸟或小鱼，并参考当前画板设定。尚未接入通用语义模型、语音或图片主体提取服务。

最新交互：素材盒短按只提示，长按约 420ms 后拖到画布目标位置添加；直接滑动仍用于浏览。画布素材拖到左侧垃圾桶后松手删除，可撤销。素材盒新增本地 PNG/JPG/WebP 上传（20MB、1600万像素以内），IndexedDB 保留原文件；未实现摄像头、语音或自动抠图。设备外框独立采用深色金属外观，应用内部仍为圆润彩色界面。

助手可重复触发：累计三次完成操作、自然停顿 6.5 秒，并满足 60 秒冷却；素材盒、作品集和弹窗打开时延后。当前提案仍是本地固定模板，不是联网语义模型。

儿童视觉版：奶油白创作区、草绿设备与工具栏、鹅黄随机取材按钮、圆润素材盒和装裱弹窗。写实素材和木框保持不变；小恐龙助手仅随原有提案条件出现，不常驻。主题样式集中在 `src/garden.css`，不改变拖动、缩放和保存逻辑。

平板版更新：4:3 横向设备外框、平面化图标工具栏、可收起素材盒、触发后才出现的助手浮窗。素材已替换为内置 imagegen 生成的写实透明 PNG，位于 `assets/real`；提示词记录在该目录的 `GENERATION.md`。保存打开画框预览，可下载带框图片或调用系统分享。

抓取使用固定接触点与角惯性计算：叶角跟随手指，其他部分随牵引旋转。当前不模拟叶片弯折/软体变形。可在 Codex 中打开本地仓库并读取 `HANDOFF.md` 继续开发。

儿童主导的智能拼贴画板原型。当前版本聚焦创作阶段：使用预置透明 PNG 素材，自由拖拽拼贴，并在连续操作后的自然停顿中低打扰地提出一个需要许可的创意建议。

## 本地运行

初始图片包现在随代码和网页一起提供：`assets/real/` 包含六件写实素材与木框纹理，`assets/assistant/` 包含恐龙头像。首次克隆不再需要额外下载；旧 Release 素材包保留作为历史备份。个人作品、上传照片和密钥不包含在初始包内。

试用版暂停生图：`src/features.js` 的 `GENERATION_ENABLED=false` 同时关闭上传生成入口和本机生成接口。拼贴、AI 本地提案、保存与画廊不受影响；静态试用站没有模型密钥或生图服务。

建议演示：新建画板，添加一次随机素材，再实际拖动并放下素材两次，收起素材库并停止操作约 6.5 秒。需要画板有空位、预置叶片和纽扣未被移出库、无弹窗且页面可见。拒绝或完成后有 60 秒冷却，需要再完成 3 次操作；不是仅触发一次。画板记忆若排除现有模板，也不会强行提案。

```bash
npm install
npm run dev
```

## V1 已包含

- PixiJS 画布初始化与透明 PNG 素材加载。
- 直接拖拽、轻微旋转/抬起阴影与落下回弹；不使用完整物理引擎。
- 素材库支持单指/鼠标拖动横向浏览、展开网格纵向浏览；轻点添加，长按后可拖入画板。
- 无骰子图标的随机取材入口将三件材料沿弧线投向画板，支持整批撤销与减少动态效果偏好。
- 重叠素材按透明像素命中，默认上层优先；按住 `Alt / Option` 点击或长按 550ms 循环选择底层。点击不改变层级，真正拖动才置顶，撤销会恢复原层级。
- 选中显示贴合透明轮廓的淡色光晕，不显示矩形框；拖动改为抬起阴影与树枝指针。移动或素材缩放结束后自动取消选中和高亮，下次调整需重新选中。
- 平板区域内触控板捏合：有选中素材时调整素材大小，否则围绕指针缩放画布。普通双指滑动平移画布，素材库内则滚动列表；右下角提供共用缩放逻辑的加减与画布复位按钮。
- 画布视图缩放不影响作品尺寸、保存和导出。素材缩放保留中心，连续缩放合并为一次撤销。
- 拖拽时轻微抬起/旋转，松开稳定；选中后可用方向键微调，Escape 取消正在进行的拖拽。
- 自动本地保存、手动保存与刷新恢复；画板切换器保留多份作品，每份保存素材位置/旋转/缩放和独立场景记忆。
- 提案演示：三次完整操作后自然停顿 6.5 秒才出现，拖拽中和页面隐藏时不触发。回应后冷却 60 秒，并要求新的操作才能再次触发。
- 提案明确征求“两片叶子和一颗纽扣拼个小伙伴”的许可。接受后，助手用新副本逐件拼贴（约 6.3 秒），以带小星标的树枝显示动作；不移动已有素材，不锁住画布。
- 共拼期间可停止；抓住助手素材即接管并停止后续添加。无空位不开始，目标被占用则停止；切画板、装裱、页面隐藏或调整窗口也停止。部分结果保留，可整批撤销。
- 撤销按对象变更记录，共拼整批撤销不抹掉儿童同时完成的操作。完成后助手和停止浮窗消失，冷却 60 秒。
- 拒绝无需解释；纠正仅追加到当前画板，不视作执行许可。当前形象为本地固定模板，不声称理解场景或按语义约束规划。

## 提案能力边界

当前为本地规则与预设文案模拟，没有接入在线语言模型，不进行真正的图像/场景语义理解。记忆会保存，但不会自动解析儿童反馈里的完整场景约束。素材不会被自动命名；素材按钮的无障碍标签仅用于辨识预置材料。

## 本地预览与验证

```bash
npm run dev -- --host 127.0.0.1
npm run build
```

仅绑定本机地址。安装会生成 `package-lock.json`，之后可以使用 `npm ci` 恢复相同依赖。若 npm 无法直连，按本机已有代理配置给当前安装命令传入代理参数，不修改全局 npm 配置。

浏览器中的作品存在当前来源的 localStorage 内，不会上传；清理浏览器数据会移除这些作品。新建画板保留原作品。清空画板需要确认。

## 暂不包含

拍照、主体分割、语音识别、摄像头监控、自动命名、未经许可或语言命令驱动的自动拼贴、公开分享与部署。

## 照片 → 胶带素材（本机服务）

在项目根目录 `.env.local` 中配置 `DASHSCOPE_API_KEY`（参考 `.env.example`），使用北京地域的 DashScope 密钥；不要使用 `VITE_` 前缀。重启 `npm run dev` 后，从素材库加号上传照片。

- 原图先存入本机 IndexedDB，再将缩至最长边 1536px 的图片发送到阿里云。
- `qwen3-vl-flash` 识别主体；`qwen-image-edit-plus` 按 make-tape-collage 的材质规则重建主体，单次生成一张，不自动重试。
- 服务端下载结果，浏览器去除指定色底并验证透明边缘，保存透明 PNG 后自动入库，不要求确认、不自动放到画板。去底属于色键处理，不是通用精细分割；复杂孔洞、近似底色及细边仍需真实生成样本验证。
- 上传记录入口可下载原图与已生成的原始结果；生成失败不把原照片冒充胶带素材。已有上传素材保持兼容。
- 原图与生成结果保存在当前浏览器来源下，清除浏览器数据会丢失；需要长期备份请下载。页面刷新不会自动重发付费请求。若在生成过程中刷新，服务器可能仍完成并计费，但结果可能未保存；请等完成再刷新。
- 额度耗尽使用指定弹窗；认证失败、限流和本机存储不足分别提示。免费额度专用模式用尽也会提示额度问题，开发者需检查平台的免费额度模式开关。
- 接口仅开放在本机 Vite dev/preview 服务；纯静态 `dist` 不包含生图后端。没有公开部署。密钥不写入客户端包或 Git。
